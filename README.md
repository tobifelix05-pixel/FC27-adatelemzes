# EA SPORTS FC 27 – játékosadatok elemzése

Kezdő szintű Python-adatelemzési szorgalmi projekt. 5 kérdés, Pandas, NumPy és Plotly.

## Indítás
1. Telepítsd a Python 3-at és a Jupyter Notebookot.
2. A projekt mappájában futtasd: `pip install -r requirements.txt`
3. Nyisd meg a `FC27_elemzes.ipynb` fájlt Jupyterben.
4. Válaszd a **Run All** lehetőséget. Az első futtatáskor a notebook interneten letölti a CSV-adatokat.
5. Ha a letöltés sikertelen, töltsd le a `players.csv` fájlt az alábbi forrásprojekt `EA_FC_PLAYERS_DATASET_AND_ DASHBOARD/data/` mappájából, és helyezd a notebook mellé.

## Az öt kérdés
1. Kik a legmagasabb értékelésű játékosok?
2. Melyik poszton legmagasabb az átlagos értékelés?
3. Van kapcsolat a gyorsaság és az összértékelés között?
4. Mely országokból szerepel a legtöbb játékos?
5. Van kapcsolat a lövés és a passzolás között?
